# Atlantino

Atlantino is a browser-based platform game inspired by the idea of a samurai-themed adventure. The project was built as a simple web game using JavaScript, Express, and Socket.IO, with a focus on learning game development and real-time web interactions during my school days.

> This project was created before AI coding tools became common. No AI-generated code was used in this project, and it was made during my school years while learning and experimenting.

## Game concept

The project is described as "Tales of samurai" and is centered around a lightweight platform-style gameplay experience. It was designed as a fun creative project to explore web game development, animation, and multiplayer-ready real-time communication.

## Features

- Browser-based game experience
- Samurai-themed concept and world design
- JavaScript-driven gameplay logic
- Express server for serving the game
- Socket.IO support for real-time communication
- Simple project structure built for learning and experimentation

## Tech stack

- JavaScript
- HTML
- CSS
- Node.js
- Express
- Socket.IO

## Run locally

1. Clone the repository:

   ```bash
   git clone https://github.com/JunaithSM/Atlantino.git
   cd Atlantino
   ```

2. Install dependencies:

   ```bash
   npm install
   ```

3. Start the server:

   ```bash
   npm start
   ```

4. Open your browser and visit:

   ```text
   http://localhost:3000
   ```

## Project structure

- `app.js` — server setup and game entry point
- `public/` — frontend assets and client-side game files
- `package.json` — project dependencies and scripts
